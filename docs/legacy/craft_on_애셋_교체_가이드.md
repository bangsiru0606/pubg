# 애셋 교체 가이드 (인수인계용)

> 지금 씬에 보이는 모든 그래픽(색깔 사각형, 체크무늬 배경)은 전부 `Assets/Editor/StoryBuilder.cs`가 절차적으로 생성한 **placeholder**입니다. 실제 아트를 완성하면 이 문서에 정리된 경로에 **같은 파일명으로 덮어쓰기만 하면** 대부분 자동으로 반영됩니다 (스프라이트 임포트 설정도 빌드 스크립트가 자동으로 다시 적용함).

---

## 0. 교체 원칙

- **파일명을 그대로 유지**하고 내용만 바꾸면, `Tools > 병원의 고해 > 전체 스토리 빌드`를 다시 실행할 때 자동으로 새 이미지를 임포트해서 씬에 반영합니다.
- 기준 해상도: **32 PPU (Pixels Per Unit)** — 1 유닛 = 32px.
- **캐릭터(플레이어/NPC)는 세로:가로 = 2:1 비율, 기준 32 x 64px** (현실적인 인체 비율). 오브젝트(단서/문/계단 아이콘)는 기존처럼 32x32px 정사각형 유지.
- **캐릭터 피벗은 하단 중앙(발밑)** 으로 고정되어 있습니다 (`StoryBuilder.cs`의 `SpriteAlignment.BottomCenter`). 새 캐릭터 이미지도 **발이 이미지 맨 아래 가장자리에 오도록** 그려야 바닥선에 정확히 맞습니다 — 위쪽에 여백을 두면 캐릭터가 붕 떠 보입니다.
- 배경은 `Assets/Art/Backgrounds/`, 캐릭터/오브젝트 아이콘은 `Assets/Art/Placeholder/`에 있습니다. **폴더/파일명을 바꾸면 반드시 `StoryBuilder.cs`도 같이 고쳐야** 합니다 (안 그러면 이미지를 못 찾음).
- PNG는 투명 배경(RGBA) 권장.

## 1. 플레이어 캐릭터 — 애니메이션 필요

**현재 파일**: `Assets/Art/Placeholder/player.png` (32x64, 2:1 비율 파란 사각형 1장, 프레임 없을 때만 사용되는 fallback)

**✅ 프레임 애니메이터 구현 완료** (`Assets/Scripts/Player/PlayerVisual.cs`). 아래 규칙대로 파일만 넣고 `Tools > 병원의 고해 > 전체 스토리 빌드`를 다시 실행하면 자동으로 프레임 애니메이션으로 전환됩니다. 파일이 하나도 없으면 지금처럼 회전+색변화 임시 연출을 계속 사용합니다 (자동 판단, 코드 수정 불필요).

**넣을 위치**: `Assets/Art/Player/`
- Idle: `idle_0.png`, `idle_1.png`, `idle_2.png` ... (0번부터 순서대로, 존재하는 만큼 자동으로 읽음)
- Walk: `walk_0.png`, `walk_1.png`, `walk_2.png`, `walk_3.png` ...

| 상태 | 권장 프레임 수 | 비고 |
|---|---|---|
| Idle (정지) | 1장 (최소) ~ 2~4장 (숨쉬기/깜빡임 등 미세 움직임) | 1장만 있어도 정상 동작 |
| Walk (걷기) | 최소 2장, 권장 4장 | 4장 = 왼발-중간-오른발-중간 |

- 이동이 **좌우(X축)뿐**이라 방향별로 따로 그릴 필요 없이 **한 방향(오른쪽 기준 권장)만 그리면** 왼쪽 이동 시 자동으로 좌우 반전(flipX)되어 나옵니다.
- 재생 속도는 `PlayerVisual` 컴포넌트의 Inspector에서 `Walk Frame Rate`(기본 8fps) / `Idle Frame Rate`(기본 2fps)로 조정 가능합니다.
- **32 x 64px(2:1), 발이 이미지 맨 아래에 오도록** 그리면 별도 스케일/피벗 조정 없이 바로 맞습니다. 프레임마다 크기가 조금씩 달라도 되지만, 발 위치(바닥 접지선)는 프레임 간에 일정하게 맞춰야 걸을 때 위아래로 튀지 않습니다.
- 참고: 지금 임시 연출(프레임 없을 때)은 정사각형이 구르는 대신 **걷는 듯 좌우로 살짝 흔들리는(wobble)** 방식으로 바뀌었습니다 (2:1 비율에서 회전은 부자연스러워서).

## 2. NPC — 정지 스프라이트 (+ 정하늘만 표정 3종)

**경로**: `Assets/Art/Placeholder/npc.png` (32x64, 2:1 비율 빨간 사각형, 현재 모든 NPC가 이 한 장을 공유, 피벗은 발밑)

NPC는 걷지 않으므로 애니메이션 불필요, **정지 스프라이트 1장씩**이면 충분합니다. 다만 각 NPC가 지금은 전부 같은 `npc.png`를 재사용 중이라, 캐릭터별로 구분하려면:
1. `Assets/Art/Placeholder/npc_백선우.png`, `npc_오미란.png` 등 캐릭터별 파일을 새로 추가
2. `StoryBuilder.cs`의 `CreateDialogueNpc(...)` 호출부에서 `SetupSprite(go, "npc", ...)` 대신 캐릭터별 키를 넘기도록 수정 (제가 처리해드릴 수 있음)
