# 맵 콘티: 씬 2~5 러프 레벨 배치도 (1D 층별 구조)

> `스토리보드_씬1-7.md`의 구역/단서/이동 방식 서술을 바탕으로 정리한 타일맵 배치 초안입니다.
> 씬 1(사무실, 이동 없음)과 씬 6~7(UI 화면)은 타일맵 대상이 아니므로 제외했습니다.
> 타일 크기는 Stardew Valley 기준 16x16px 픽셀 그리드를 가정하고, 칸 수는 "타일 개수"입니다. 실제 제작 시 조정 가능한 초안 수치입니다.

## 이동 모델 (개정)

- **오버월드 이동은 X축(좌우)만 가능한 1차원 라인**입니다. Y축 이동/2D 룸 배치는 사용하지 않습니다.
- 병원 건물은 **층(Floor)** 단위로 구성됩니다. 각 층은 하나의 가로 복도(코리도)이며, NPC·조사 오브젝트·방 출입구가 그 라인 위의 지점(point)으로 배치됩니다.
- **방(병실/사무실) 진입**은 기존과 동일하게 문 오브젝트에 다가가 엔터 → 별도 화면(그 방만의 짧은 1D 라인)으로 전환됩니다. 방은 같은 층 안에서의 화면 전환이며 층 이동이 아닙니다.
- **층간 이동은 반드시 계단 오브젝트를 통해서만** 이뤄집니다. 계단에 다가가면 하이라이트와 함께 `[N층 올라가기]` / `[N층 내려가기]` / `[지하 1층 내려가기]` 형식의 프롬프트가 뜨고, 엔터키를 누르면 해당 층으로 화면이 전환됩니다.
- 계단은 스토리 조건(단서 보유)이 충족되기 전에는 프롬프트가 뜨지 않거나 NPC가 가로막는 대사로 진입이 제한됩니다. 조건 충족 후에는 **양방향 이동이 항상 가능**합니다 (재방문 동선 확보).
- 각 층은 실제 건물처럼 **수직으로 인접한 층으로만** 계단이 연결됩니다: **지하1층↔1층↔2층↔3층**. 지하에서 3층으로, 혹은 그 반대로 곧장 이동하는 직행 계단은 없습니다 — 예를 들어 지하에서 관계자 구역(3층)으로 가려면 지하1층→1층→2층→3층 순서로 세 번 계단을 타야 합니다.

## 층 구성 개요

| 층 | 내용 | 원래 씬 |
|---|---|---|
| 1층 | 로비 + 원장실 앞 복도 (통합 코리도) | 씬 2 |
| 2층 | 병동 (다인실 여러 개) | 씬 3 |
| 3층 | 관계자 구역 (부원장실/간호사실/이혜정실) | 씬 4 |
| 지하 1층 (B1) | 지하 창고 | 씬 5 |

```
[지하 1층]  ←계단→  [1층]  ←계단→  [2층]  ←계단→  [3층]
   창고           로비+복도        병동         관계자구역
```

## 공통 표기 규칙

```
▼      플레이어 시작 위치
NPC    NPC 배치 위치
●      조사 가능 오브젝트(단서)
═문    같은 층 안 방 출입구 (엔터 → 방 화면 전환)
▲계단  층간 이동 오브젝트 (엔터 → 다른 층 화면 전환)
🔒     잠금 조건 있음
—      X축 이동 가능 구간
```

## 1층. 로비 + 원장실 앞 복도 (구 씬 2)

**길이**: 약 34타일 (로비 구간 14 + 복도 구간 20, 문 없이 하나의 연속 라인으로 통합)

```
▼시작 — ▲계단🔒[지하 1층 내려가기] — NPC백선우 — ⨯잡지꽂이(배경) — ●진료실문(장식,비상호작용) — 🔒●단서1(원장실문틈관찰)
   — ●단서2(캘린더메모) — NPC간호사(●단서3,스침연출) — ▲계단🔒[2층 올라가기]
```

| 위치(순서) | 요소 | 상호작용 | 조건 |
|---|---|---|---|
| 시작 직후 | 계단 (지하 창고행) | `[지하 1층 내려가기]` | 🔒 단서4+5+9 확보 시 활성화. 물리적으로는 초반부에 있지만 단서 게이팅이라 실제로는 2~3층을 먼저 돌고 와야 열림 |
| 이어서 | NPC 백선우 | 대화하기 → 면담 취소 시도 → 허가 → 안내 대사 후 퇴장 | 씬 진입 시 자동 트리거, 대화 끝나기 전엔 그 지점 통과 불가(NPC가 가로막음) |
| 중간 | 진료실 문 | 없음 (장식, "출입 자제" 대사만) | - |
| 중간 | 원장실 문 | "조사하기" → 문틈 관찰 → 단서1 | 문 자체는 열리지 않음(잠김 고정) |
| 후반 | 캘린더 메모 | "조사하기" → 근접 조사(마우스) → 단서2 | - |
| 후반 | NPC 간호사 | 스쳐 지나가며 서류 낙하 → 단서3 (근접 조사) | 백선우 퇴장 후 등장 |
| 라인 끝 | 계단 | `[2층 올라가기]` | 🔒 단서1 + 단서2 확보 시 프롬프트 활성화 |

## 2층. 병동 (구 씬 3)

**길이**: 약 26타일 (복도 라인, 병실은 별도 화면)

```
▼계단에서진입[1층 내려가기] — ═1병실(잠김/배경) — ═2병실(최옥자) — ═3병실(한유진)
   — ═4병실(채소연+정하늘) — ▲계단🔒[3층 올라가기]
```

| 위치(순서) | 요소 | 상호작용 | 조건 |
|---|---|---|---|
| 진입점 | 계단 | `[1층 내려가기]` (역방향 이동) | 항상 가능 |
| 1병실 | 배경용(구 박은지 병실), 빈 침대 | 조사 시 짧은 텍스트(선택) | 필수 아님 |
| 2병실 | NPC 최옥자 할머니 | 대화하기 → 단서4 | - |
| 3병실 | NPC 한유진 | 대화하기 → 단서5 | - |
| 4병실 | NPC 채소연, NPC 정하늘(1차), 소품(화학 자격증) | 채소연: 단서6·단서10 / 정하늘: 1차 대면(심증만, 단서 없음) | - |
| 라인 끝 | 계단 | `[3층 올라가기]` | 🔒 단서4 + 단서5 확보 시 활성화 |

**병실 내부(예: 4병실)** — 각 방도 짧은 1D 라인, 길이 약 8~10타일
```
입구 — 침대들(배경) — NPC채소연 — NPC정하늘 — ●소품:화학자격증(배경조사)
```

**정하늘 2차 재방문**: 단서9 확보 후 4병실 문 위에 '!' 아이콘 표시. 플레이어는 3층에서 `[2층 내려가기]` 계단을 타고 2층으로 돌아와 4병실에 재진입해야 함.

## 3층. 관계자 구역 (구 씬 4)

**길이**: 약 20타일

```
▼계단에서진입[2층 내려가기] — ═백선우부원장실 — ═오미란간호사실 — ═이혜정개인실
```

| 위치(순서) | 요소 | 상호작용 | 조건 |
|---|---|---|---|
| 진입점 | 계단 | `[2층 내려가기]` (역방향 이동, 정하늘 2·3차 재방문 및 지하 이동 경유용) | 항상 가능 |
| 부원장실 | NPC 백선우 | 대화하기(단서2·3 제시) → 단서7 | 순서 무관 자유 진입 |
| 간호사실 | NPC 오미란 | 대화하기(단서4·6 제시) → 단서8·단서9 | 순서 무관 자유 진입 |
| 이혜정실 | NPC 이혜정 | 대화하기(단서7·9 제시) → 단서12·단서13 | 순서 무관 자유 진입 |

> 정하늘은 이 층에 없습니다. 2차 대면은 위 "2층 내려가기" 계단으로 병동에 돌아가 4병실에서 진행합니다. 3층은 지하와 직접 연결되지 않으므로, 지하로 가려면 `[2층 내려가기]` → `[1층 내려가기]` → 1층의 `[지하 1층 내려가기]` 순으로 내려가야 합니다.

## 지하 1층. 숨겨진 창고 (구 씬 5)

**길이**: 약 18타일

```
▼계단에서진입[1층 올라가기] — ●단서15(의료장비/냉장보관함,배경조사) — ●단서14(지하장부,책상)
   — ●단서16(박은지유품,보관함) — ▲계단[1층 올라가기]
```

| 위치(순서) | 요소 | 상호작용 | 조건 |
|---|---|---|---|
| 진입점/라인 끝 | 계단 | `[1층 올라가기]` (역방향 이동) | 항상 가능. 이 층은 왕복만 하는 막다른 구조라 계단이 사실상 한 지점 |
| 중반 | 의료 장비/냉장 보관함 | "조사하기" → 단서15 (배경 물증, 텍스트만) | - |
| 중반 | 지하 장부(책상) | "조사하기" → 근접 조사 → 단서14 + 단서17(필체 대조, 팝업 내 연출) | - |
| 후반 | 박은지 유품(보관함) | "조사하기" → 근접 조사 → 단서16 | - |

**정하늘 3차 재방문(최종 고백)**: 단서16 확보 후, `[1층 올라가기]` → `[2층 올라가기]` 두 번의 계단 이동을 거쳐 4병실로 돌아가면 '!' 아이콘과 함께 최종 고백 대화가 열림.

## 층 간 이동 및 스토리 진행 순서도

```
1층(로비+복도)
   └─ 단서1+2 ─▶ [2층 올라가기] ─▶ 2층(병동: 최옥자/한유진/채소연/정하늘1차)
                                        └─ 단서4+5 ─▶ [3층 올라가기] ─▶ 3층(백선우/오미란/이혜정)
                                                                            │
                                             단서9 확보 시 [2층 내려가기] ◀─┘─▶ 정하늘 2차(4병실)
                                                                            │
                                    (지하로 가려면 [2층 내려가기]→[1층 내려가기] 경유)
                                                                            │
                                             단서4+5+9 ─▶ 1층의 [지하 1층 내려가기] ─▶ 지하1층(창고)
                                                                                    │
                                            단서16 확보 시 [1층 올라가기]→[2층 올라가기] ─▶ 정하늘 3차(4병실)
                                                                                    │
                                                             단서16+17 ─▶ 씬6(추리판)
```

> 지하1층은 3층이 아니라 **1층**과 직접 연결됩니다 (건물 구조상 자연스러운 지하1↔1↔2↔3 순서). 3층에서 지하로 가려면 2층→1층을 거쳐야 합니다.

## 길이 요약 (타일맵 제작 참고용)

| 층 | 구간 | 길이(타일, 16x16px 기준) |
|---|---|---|
| 1층 | 로비+복도 통합 라인 | 34 |
| 2층 | 병동 복도 라인 | 26 |
| 2층 | 병실 내부 (x4) | 8~10 |
| 3층 | 관계자 구역 라인 | 20 |
| 3층 | 사무실 내부 (x3) | 8~10 |
| 지하1층 | 창고 라인 | 18 |

> 1주차 프로토타입 대상인 1층(구 씬2)은 34타일짜리 단일 라인 하나뿐이라 `IInteractable` + 1D 이동 + 상호작용 프롬프트 UI + 계단 층 전환 검증에 가장 작고 적합한 규모입니다. 2~3층/지하1층은 같은 라인+계단 구조를 복제해 오브젝트만 바꾸는 형태라 이후 진행이 반복 작업으로 처리됩니다.
