# 사운드 계획 — 『병원의 고해』

> 효과음은 Codex가 **코드로 합성**해 만든다. 배경음악은 사용자가 **ElevenLabs Music 무료 플랜**(1순위) 또는 **ACE-Step**(오픈소스, 2순위)으로 만든다. Suno 무료 플랜은 쓰지 않는다(1.3).
> 게임 삽입은 Claude Code가 한다. 모든 경로는 `D:\game` 기준이다.

---

## 0. 원칙

- 소리는 분위기를 돕는 정도로만 쓴다. 대사·단서 정보는 소리에 의존하지 않는다(소리를 꺼도 플레이 가능).
- 정답·오답을 소리로 미리 알려주지 않는다. 퍼즐 확인 버튼을 누른 뒤의 결과음만 허용하고, 사건 수첩의 결론 저장은 중립음 하나만 쓴다.
- 브라우저 자동 재생 제한: 첫 소리는 타이틀에서 사용자가 키·클릭으로 시작한 뒤에만 낸다.
- 더블클릭(`file://`) 실행 호환: 소리는 `./assets/audio/...` 상대경로 파일을 `<audio>`(HTMLAudioElement)로 재생한다. `fetch`·`decodeAudioData`로 파일을 읽지 않는다.
- 용량 예산: 소리 전체 12MB 이하(zip 전체 15MB 이하 유지).

## 1. 배경음악 (사용자 제작)

### 1.1 도구와 사용 방법
**1순위: ElevenLabs Music (무료 플랜)**
- 웹에서 프롬프트로 생성. 가사 없이(instrumental) 생성하고, 길이는 1~2분으로 지정한다.
- 무료 플랜 결과물은 **비상업적 공유만 허용**, 배포할 때 **"Eleven Music"을 출처로 표기**해야 한다(ElevenLabs 도움말 기준). 판매·광고·수익 창출 금지.

**2순위: ACE-Step (오픈소스, MIT/Apache 계열 라이선스)**
- 사용 제한이 가장 적다. 내 PC(NVIDIA GPU 필요) 또는 Hugging Face Space에서 무료로 실행한다.
- ElevenLabs 무료 크레딧이 모자라거나, 상업적 제약이 없는 곡이 필요할 때 쓴다.

**공통**
- 아래 영어 프롬프트를 그대로 쓴다. 실존 가수·작곡가·곡 이름은 넣지 않는다.
- 결과 중 단조롭고 반복하기 좋은 쪽을 고른다. 갑자기 커지는 구간·드럼 브레이크·목소리가 있으면 버린다.
- MP3로 내려받아 `D:\game\art\source\audio\bgm\<파일명>.mp3`로 저장한다.
- 곡마다 사용 도구, 생성 날짜, (있으면) 곡 링크를 `art/source/audio/bgm/CREDITS.md`에 적는다(README 출처 표기에 사용).

### 1.3 이용 조건 정리
- **ElevenLabs Music 무료**: 비상업적 이용, "Eleven Music" 출처 표기 필수. README와 게임 크레딧 화면(타이틀 → 정보)에 표기한다.
- **ACE-Step**: 오픈소스 모델이라 결과물 사용 제약이 거의 없다. README에 "ACE-Step으로 생성"을 적는다.
- **Suno 무료 플랜은 쓰지 않는다**: 결과물 권리를 Suno가 갖고 개인적·비상업적 이용만 허용되며, 무료 플랜에서는 내려받기 자체가 제한된다는 정리도 있다.
- 대회 규정에 AI 생성 음악 관련 조항이 있는지 확인하고, 애매하면 운영진에게 묻는다.

## 2. 효과음 (Codex, 코드 합성)

### 2.1 방식
- `tools/sfx/generate-sfx.ts`(또는 .mjs)가 **외부 라이브러리·외부 음원 없이** 사인파·노이즈·엔벨로프·필터를 직접 계산해 WAV(44.1kHz, 16bit, 모노)를 만든다. 같은 코드면 항상 같은 소리가 나오게 난수 시드를 고정한다.
- 출력: `art/source/audio/sfx/<이름>.wav`. 명령: `npm run sfx`.
- 각 효과음의 합성 파라미터는 `tools/sfx/sfx-spec.json`에 데이터로 둔다(코드 수정 없이 조정 가능).
- 음량: 최대 피크 -3dBFS, 효과음끼리 체감 음량을 비슷하게 맞춘다. 앞뒤에 클릭 잡음이 없도록 5ms 이상 페이드.

### 2.2 목록

| 이름 | 쓰는 곳 | 소리 설계 |
|---|---|---|
| `knock` | 씬 1 노크 | 나무문 노크 3번(저역 쿵 + 짧은 노이즈), 간격 약 0.25초 |
| `door_open` | 문 들어갈 때 | 낮은 경첩 삐걱(느린 주파수 미끄럼) + 짧은 쿵 |

| `footstep` | 걷기(선택, 아주 작게) | 짧고 부드러운 발소리 2종(번갈아 재생) |
| `page_flip` | 원문 보기·수첩 열기 | 종이 넘김(대역 통과 노이즈 스윕) |

| `ui_confirm` | 선택 확정·결론 저장 | 짧은 중립 클릭(정답 여부와 무관하게 같은 소리) |

## 3. 게임 삽입 규칙 (Claude Code)

- `src/audio/` 오디오 관리자: BGM 1채널(교차 페이드 1.5초), 효과음 다채널(같은 소리 동시 재생 최대 3).
- 어떤 장면에서 어떤 BGM을 쓸지는 `src/data/audio.json`에 데이터로 둔다(구역·대화·퍼즐·씬 이벤트 → 트랙). 코드에 하드코딩하지 않는다.
- 효과음 연결도 데이터 이벤트 이름으로 한다(`onEvidenceGet` → `evidence_get` 등).
- 음량: 마스터·BGM·효과음 3개 슬라이더(타이틀 "설정"), `M` 키로 전체 음소거, 값은 저장(localStorage try/catch).
- 첫 재생: 타이틀에서 첫 키 입력·클릭 이후. 그 전에는 화면 하단에 "아무 키나 눌러 시작" 안내.
- 파일이 없으면 무음으로 진행한다(오류 없음). validate는 `audio.json`이 참조하는 파일 중 없는 것을 경고, 아무 데서도 쓰지 않는 파일을 경고.
- 정규화(`npm run assets`): BGM은 MP3 96~128kbps로, 효과음 WAV는 OGG 또는 짧은 WAV로 `public/assets/audio/`에 복사·변환한다(변환 도구가 없으면 원본 복사). 용량 예산 12MB를 넘으면 실패.
- test:release: Chrome·Edge에서 `file://`로 열어 첫 입력 후 BGM이 재생 상태가 되는지, 콘솔 오류 0인지 확인.
